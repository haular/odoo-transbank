Este módulo proporciona la integración base para los servicios de pago de Transbank en Chile.
Utiliza el SDK oficial de Transbank para garantizar transacciones seguras y confiables.

Instalación
===========

1.  Instale este módulo ``payment_transbank``.
2.  La librería python ``transbank-sdk`` debe estar instalada en su entorno.

Configuración
=============

Este es un módulo base. Para habilitar métodos de pago específicos, instale los módulos correspondientes, como ``payment_transbank_webpay``.
